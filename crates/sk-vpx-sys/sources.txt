# The libvpx 1.17.0 C files compiled for the VP9 decoder, relative to libvpx/.
#
# build.rs compiles them; tools/vendor-libvpx.ts vendors exactly these and the
# headers they include. Derived from libvpx's own make fragments for this
# configuration (vpx/vpx_codec.mk API_SRCS, vpx_scale/vpx_scale.mk,
# vpx_dsp/vpx_dsp.mk DSP_SRCS, vpx_util/vpx_util.mk, vp9/vp9_common.mk and
# vp9/vp9dx.mk VP9_DX_SRCS), then trimmed to what the decoder links:
#
# * no `.asm` (no nasm; config/asm-only.txt and csrc/sk_vpx_asm_shim.c cover it)
# * no vpx_mem/vpx_mem.c (csrc/sk_vpx_mem.c replaces it, with accounting)
# * no vpx/src/vpx_encoder.c, vpx_dsp/skin_detection.c,
#   vpx_util/vpx_write_yuv_frame.c, vpx_scale/generic/vpx_scale.c,
#   vpx_scale/generic/gen_scalers.c: the make fragments list them, the decoder
#   never calls them.
#
# [c] is compiled for every target. [x86_64] only with the x86_64-msvc config
# (intrinsics; a `_avx2.c` file gets /arch:AVX2).
