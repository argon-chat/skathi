# The x86_64 rtcd specialisations libvpx 1.17.0 implements only in assembly.
#
# sk-vpx-sys builds without nasm, so tools/vendor-libvpx.ts points each one back
# at what the CPU would get without it: a `#define NAME NAME_sse2` becomes
# `#define NAME NAME_c` (SSE2 is the x86_64 baseline; below it there is only C),
# and an `if (flags & HAS_SSSE3) NAME = NAME_ssse3;` line is dropped (the
# dispatch keeps the C default). The tool fails if an entry no longer matches
# exactly one line, so the list cannot drift silently across a bump.
#
