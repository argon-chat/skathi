0.8.5 was about how text looks. 0.9 is about the parts of an app that are not text: video and sound that feed the GPU and the audio graph, effects over what is behind them, and windows that behave the same on a Mac as on Windows. A good share of it came from people porting real apps, and the issue numbers are in the text.

## Media as input

**Video in WebGPU.** An HTML `<video>` and a `VideoFrame` can supply the pixels of a WebGPU texture. On DirectX 12 and Metal a frame can go straight into a `texture_external` binding; on Vulkan it is copied in. A frame keeps the media's resolution whatever size the element is painted at. The optional WebGPU features the adapter has are exposed too, and a device opts into them through `requiredFeatures`. ([#91](https://github.com/argon-chat/skathi/issues/91), [#92](https://github.com/argon-chat/skathi/issues/92))

**Element audio in Web Audio.** The sound of an `<audio>` or `<video>` element can pass through an analyser, a filter, a gain or a panner. Attaching an element source moves its playback into the graph, and the route survives a change of `src`. `BiquadFilterNode` and `MediaStreamAudioDestinationNode` carry up to 32 channels.

## Variable fonts

`font-stretch` (and `font-width`) sets the `wdth` axis, `font-style: oblique <angle>` the `slnt` axis, `italic` the `ital` axis or a slant, and `font-variation-settings` any axis, applied last. The `@font-face` descriptors of the same names clamp and seed them, and the faces of a family are matched by width first. `getComputedStyle` returns all of them.

A fix that goes with it: an `@font-face` with a weight range on one variable file, such as `font-weight: 300 900`, was drawn at the file's default instance on macOS and Linux whatever weight the text asked for. The text's weight now selects the instance.

## Backdrop effects

An effect that reads its backdrop used to make the renderer copy the whole window, because an effect may sample anywhere. A glass bar at the bottom of a full-screen window paid for the full screen on every frame.

An effect can now say how far it reads. Mark a length parameter with `[SkBackdropReach]`:

```slang
[SkEffect("glass")]
struct Glass : IEffect
{
    [SkLength] [SkBackdropReach] float depth;

    float4 shade(EffectInput input) { /* ... */ }
}
```

The renderer then copies and blurs only the element's box grown by that length, on Metal, DirectX 12 and wgpu alike, and a read beyond it is clamped to that edge. The marker implies `[SkBackdrop]`. An effect without it works as before. ([#130](https://github.com/argon-chat/skathi/issues/130))

## Windows

**`appWindow.theme` on macOS.** A forced theme now sets the AppKit appearance of the app and of every window, pop-outs included, so the traffic lights, the window frame, vibrancy, and the panels and menus the system opens for the app follow it. Before, only `prefers-color-scheme` did. A new `"window": { "theme" }` key in sk.config.json sets the starting theme on every platform, before the window is first shown, so a dark app does not flash light. ([#117](https://github.com/argon-chat/skathi/issues/117))

**Pop-outs on macOS.** `focusable={false}` makes a pop-out a non-activating panel: a click reaches it and the main window stays key. `taskbar={false}` makes it a child of the main window, so it moves, hides and minimizes with it. `mapFromMain()` holds across displays. ([#118](https://github.com/argon-chat/skathi/issues/118), [#119](https://github.com/argon-chat/skathi/issues/119), [#120](https://github.com/argon-chat/skathi/issues/120))

**`appShell` on macOS.** `openExternal`, `openPath`, `showItemInFolder` and `trashItem` work there, with the error names Windows and Linux use. A URL or file nothing opens rejects instead of prompting.

**`appWindow.startResizeDragging(direction?)`** starts the system resize from an edge or a corner while the left button is held, on Windows and Linux. Without a direction it takes the edge nearest the pointer. ([#122](https://github.com/argon-chat/skathi/issues/122))

**`matchMedia`** no longer keeps every query forever. A query lives while it has a `change` listener or `onchange`, and queries are evaluated again only when the environment changes.

## Images

`ImageDecoder` reads nine more types: ICO and CUR, TIFF, PNM, SVG, QOI, TGA, Radiance HDR, farbfeld and DDS. `ImageEncoder` writes GIF, ICO, BMP, QOI, TIFF, TGA, PNM, farbfeld and Radiance HDR, one image each.

Most of these codecs were already in the host for `<img>`, so they add little to its size. Everything still decodes to 8-bit RGBA: HDR values above white are clamped, and a multi-page TIFF gives its first page. An SVG is drawn by the renderer `<img>` uses, directly at the size asked for.

## The mouse wheel

A notch of the wheel used to move different things by different amounts: 48 px in `WheelEvent`, and a line height of its own in each scroll container, `<textarea>` and `<sk-editor>`. It is now what Chromium reports on each platform, 100 px on Windows at the system default, and everything the app scrolls moves by that distance. ([#121](https://github.com/argon-chat/skathi/issues/121))

An app that wants another speed sets it once:

```json
{ "input": { "wheelScrollScale": 1.5 } }
```

or at run time with `app.wheelScrollScale` from `skathi:app`. It scales the app's own scrolling; `WheelEvent` deltas and touchpad scrolling are not scaled.

## Fixes worth knowing

- A rule with `:focus-within` on the element itself was matched but never painted. ([#124](https://github.com/argon-chat/skathi/issues/124))
- Where several rules with states set the same property, the later rule wins as in a browser, and a selector with two states applies only while both hold. ([#125](https://github.com/argon-chat/skathi/issues/125))
- `box-shadow` blur is as wide as a browser draws it; it was twice as soft. ([#126](https://github.com/argon-chat/skathi/issues/126))
- `<button>` and `input[type=button|submit|reset]` centre their text by default. ([#123](https://github.com/argon-chat/skathi/issues/123))
- `<sk-layer>`: the corner radii an embedder receives are in device pixels; they were scaled twice. The opacity is the one the element is shown at, its ancestors' included, so a layer fades with a parent that fades. ([#128](https://github.com/argon-chat/skathi/pull/128))
- Windows, HDR: translucent content over a transparent window (`backdrop: "mica"` and the like) was several times too bright, a `glow()` halo most visibly. It is now as bright as in an SDR window.
- A `<textarea>` no longer scrolls back to the caret on every frame, so the wheel can move it away.
- Windows: with an aspect ratio set, dragging a corner no longer swings the window between a wide and a tall fit. ([#116](https://github.com/argon-chat/skathi/issues/116))
- macOS, embedded: Cmd+Q quits at once instead of waiting out a four-second deadline. ([#112](https://github.com/argon-chat/skathi/issues/112))
- Layout moves to taffy 0.16: overflowing flex lines under a stretch alignment fall back to `flex-start`, and `calc()` track sizes count as fixed for `auto-fill` and `auto-fit`.

<Aside kind="warning" title="What 0.9 does not do yet">

- **Backdrop reach.** The built-in `frost` still copies the whole window, and so does an effect inside an effect layer.
- **`startResizeDragging`** does nothing on macOS, where AppKit has no call for it.
- **The window theme** on Linux still reaches only `prefers-color-scheme`.

</Aside>

## Upgrading

Run the commands at the top of this post and `bunx sk check`.

- Rebuild the app: effects compiled by an earlier `sk` are refused by the 0.9 host.
- A wheel notch scrolls farther than before, about twice as far on Windows. `"input": { "wheelScrollScale": 0.5 }` brings the old distance back.
- A button wider than its label shows the label in the middle. `text-align: left` on it restores the old look.
- `box-shadow` blur is half as soft for the same value. Double the blur radius where a design was tuned by eye.
- For embedders: divide `<sk-layer>` radii by the scale no more; they arrive in device pixels.
- Removed: `appWindow.setProgressBar`, `setOverlayIcon`, `setSkipTaskbar`, `setIcon`, `setBadgeCount` and `getScreenDetails`, which only printed an advisory.
