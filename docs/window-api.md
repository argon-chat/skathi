# Window API

What a Skathi app can do with its windows: the main window (`appWindow`), its events, the startup
options in `sk.config.json`, custom title bars, pop-out windows (`<SkWindow>`) and the taskbar or dock.
For the concepts and complete scenarios, start with the [Windows guide](/guides/windows/).

Every entry has its own page: the signature, the support on Windows, macOS and Linux, the release it
arrived in, examples and the edge cases worth knowing.
