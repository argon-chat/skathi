# create-skathi

Starts a new [Skathi](https://github.com/argon-chat/skathi) app: desktop apps from Vue 3 and Svelte 5
components, rendered on the GPU without a browser.

```
bun create skathi my-app
```

It asks for a template (showcase, minimal, svelte, player, weather, draw, chip8 or sequencer), the platforms to package for and the package
manager. The options of `sk create` work here too:

```
bun create skathi my-app --template minimal --yes
```
